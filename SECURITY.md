# Security policy

## Reporting a problem

If you find a security problem in ChurchRadio Studio, please report it privately. **Do not open a
public issue.**

- **Preferred:** use GitHub's private reporting. On this repository, open the **Security** tab and
  click **Report a vulnerability**.
- **Or email** [admin@leavenlabs.org](mailto:admin@leavenlabs.org).

Please include:

- the ChurchRadio Studio version (shown in the app's **About** box) and your Windows version;
- the steps to reproduce the problem;
- what an attacker could do with it.

## What to expect

ChurchRadio Studio is a volunteer project published by Leaven Labs. You will get a reply within
7 days. Fixes are made on a best-effort basis, and you will be told when a fixed release is out.
Please give us a reasonable time to release a fix before you share details publicly.

## Supported versions

Only the newest release receives fixes. To update, download the newest
`ChurchRadio-Studio-Setup.exe` from the [Releases](../../releases) page and run it.

## Scope

In scope: the ChurchRadio Studio app, its installer, and the release build in this repository.

Problems in the software it includes, such as FFmpeg, faster-whisper or the Whisper speech models,
should be reported to those projects. If such a problem affects ChurchRadio Studio, please tell us
as well so we can ship an updated release.
